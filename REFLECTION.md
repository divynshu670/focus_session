# Reflection

Building Focus Sessions helped me understand how to break a Flutter application into smaller, manageable components while using AI as a development assistant.

### Where Claude Saved Me the Most Time

Claude helped me understand the project structure, identify suitable packages and work through implementation details. It was particularly useful for creating the initial models, separating repositories from providers and understanding test cases.

### Where Claude Cost Me Time

Some generated code required closer inspection and corrections. I learned that code can look correct but still contain logical issues, especially around timer calculations, date comparisons and duplicate session handling. Reviewing the implementation and running tests was necessary rather than relying only on generated suggestions.

### What I Would Do Differently Next Time

I would spend more time defining edge cases and writing tests before implementing each feature. I would also review smaller changes more frequently instead of waiting until multiple components were connected.

The main takeaway was that AI can speed up development, but understanding the generated code and verifying its behaviour remain my responsibility.
